# ☁️ Escola da Nuvem: Módulo de IA AWS e Programação Python

Este repositório contém as atividades práticas desenvolvidas durante o módulo de Inteligência Artificial e Python. O objetivo principal é consolidar o domínio da linguagem Python como base para a implementação e consumo de serviços de IA na infraestrutura AWS.

---

## 🤖 Foco em IA AWS
Este módulo prepara a base técnica para a utilização de serviços de Inteligência Artificial da AWS, tais como:
* **Análise de Dados:** Preparação de scripts Python para processamento de informações que alimentam modelos de ML.
* **Automação:** Criação de lógicas que servem de base para integração com serviços como Amazon Lex, Rekognition ou Bedrock.
* **Pensamento Computacional:** Desenvolvimento de algoritmos robustos necessários para a arquitetura de soluções em nuvem.

---

## 📂 Atividades Práticas Desenvolvidas


### 📑 Atividade Prática 01 (Fundamentos e Cálculos)
* `calculadora_preco_total.py`: Cálculo de valores com base em quantidade e preço.
* `calculadora_soma.py`: Operações aritméticas básicas.
* `calculadora_volume.py`: Cálculo de volume (geometria/espacial).
* `saudacao.py`: Primeiro contato com manipulação de strings e entradas.

### 📑 Atividade Prática 02 (Lógica Matemática)
* `calcular_consumo_combustível.py`: Cálculo de eficiência e gasto de combustível.
* `calcular_desconto.py`: Aplicação de percentagem sobre valores.
* `calcular_media_escolar.py`: Média simples entre notas.
* `conversor_moeda.py`: Manipulação de taxas de câmbio.

### 📗 Atividade Prática 03 (Estruturas Condicionais)
* `calculadora_imc.py`: Cálculo de Índice de Massa Corporal com classificações.
* `classificador_idade.py`: Lógica de faixas etárias.
* `conversor_temperatura.py`: Conversão Celsius para Fahrenheit com tratamento de erro.
* `verificador_bissexto.py`: Algoritmo de validação de anos bissextos.

### 📘 Atividade Prática 04 (Loops e Lógica Avançada)
* `Analisador_numeros.py`: Classificação de pares/ímpares com relatórios finais.
* `Calculadora_basica.py`: Calculadora contínua com proteção contra divisão por zero.
* `media_turma.py`: Registro dinâmico de notas e cálculo de média acumulada.
* `verificador_senha.py`: Validação de segurança (mínimo 8 caracteres e presença de números).
